# RupeeMate

### AI-Driven Financial Coach for Students & Young Earners

---

# 🚀 Overview

**RupeeMate** is an AI-powered financial literacy and money management platform designed specifically for students, teenagers, and young professionals.

The platform helps users:

* Track expenses
* Build budgeting habits
* Visualize savings growth
* Explore SIP & SWP investments
* Receive AI-powered financial guidance
* Develop long-term financial discipline

RupeeMate simplifies finance using beginner-friendly tools, smart insights, and interactive visualizations.

---

# ❗ Problem Statement

Many students and young earners struggle with:

* Financial discipline
* Expense management
* Budget planning
* Investment understanding
* Saving consistency

Most financial platforms are:

* complex,
* jargon-heavy,
* and intimidating for beginners.

Young users often:

* spend impulsively,
* fail to track money,
* avoid investments due to fear and confusion,
* and lack personalized financial guidance.

---

# 💡 Our Solution

RupeeMate provides a smart and beginner-friendly financial ecosystem where users can:

* Track monthly expenses
* Analyze savings potential
* Explore SIP & SWP investments
* Receive AI-based budgeting suggestions
* Get financial insights in simple language
* Visualize compounding and growth
* Build smart money habits

The platform focuses on:

* simplicity,
* accessibility,
* privacy,
* and financial literacy.

# 🧠 How RupeeMate Works

1. User enters:

   * income,
   * expenses,
   * financial goals

2. System processes financial data:

   * categorizes spending,
   * analyzes savings potential,
   * tracks trends

3. AI engine generates:

   * personalized recommendations,
   * budget plans,
   * smart investment insights

4. Dashboard visualizes:

   * savings growth,
   * investment projections,
   * financial performance

# ⚙️ Installation & Setup

## Clone Repository

```bash
git clone https://github.com/your-username/rupeemate.git
```

## Navigate to Project

```bash
cd rupeemate
```

## Install Dependencies

```bash
npm install
```

## Run Development Server

```bash
npm run dev
```

Open:

```bash
http://localhost:3000
```

# 🔐 Environment Variables

Create a `.env.local` file:

NEXT_PUBLIC_SUPABASE_URL=your_url
